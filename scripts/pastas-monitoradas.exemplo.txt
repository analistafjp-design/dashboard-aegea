# SINTAXE:  CAMINHO DA PASTA = base1, base2, base3
#
# O "= base" fixa para qual base do dashboard os arquivos daquela pasta
# vão — é o mesmo efeito de escolher a aba na tela de Atualização de Dados.
# Uma pasta pode alimentar VÁRIAS bases: os arquivos são enviados uma vez
# para cada uma (é o caso da pasta Interior, cujos arquivos servem para
# Venda, Implantação e Termos).
#
# Bases aceitas: termos, faturamento, vendas, implantacao, programacao, metas
# Sem "= base", o sistema tenta identificar pelas colunas do arquivo.
#
# Subpastas entram automaticamente. Linhas com # são ignoradas.
#
# Funciona com OneDrive/Google Drive: a pasta sincronizada é uma pasta
# normal no PC, basta apontar para ela. Arquivos "somente na nuvem" são
# baixados sozinhos na leitura (a primeira execução pode demorar mais).
