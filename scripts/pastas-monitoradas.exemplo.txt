# Pastas que o dashboard vai monitorar — uma por linha.
#
# COMO PEGAR O CAMINHO: abra a pasta no Explorer do Windows, clique uma vez
# na barra de endereço no topo (o texto fica azul), Ctrl+C, e cole aqui.
#
# OPCIONAL — fixar a base de cada pasta com "= tipo" no fim da linha, do
# mesmo jeito que as abas fazem na tela de Atualização de Dados:
#
#     C:\Caminho\Da\Pasta = vendas
#
# Tipos aceitos: termos, faturamento, vendas, implantacao, programacao, metas
# Sem "= tipo", o sistema identifica a base pelas colunas do arquivo.
#
# Subpastas são incluídas automaticamente.
# Linhas começando com # são ignoradas.
